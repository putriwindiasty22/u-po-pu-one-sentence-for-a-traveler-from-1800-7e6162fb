One sentence for a traveler from 1800: a single road joining every post office and library on earth, where a letter arrives in a breath and any book you ask for opens before you — the modern internet explained with nothing a person from 1800 could not already picture.

The program is deterministic: it always writes the same sentence to `/output/entry.txt`, well inside the gate's 1–200 character limit, and refuses to write anything outside it.

## Run it

```sh
node main.ts
```
